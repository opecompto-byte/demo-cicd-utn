Arquitectura CI/CD UTN

🟢 MI VERSION PORQUE ME VOY - VERSIÓN 5.0

Despliegue 100% automatizado sin intervención humana.
Infraestructura inmutable gestionada mediante eventos.

1. Eventos (GitHub)

El código actúa como la única fuente de verdad. Los cambios impulsan eventos Webhook instantáneos a través de Ngrok.

2. Orquestación

Jenkins procesa las instrucciones del pipeline, gestionando la descarga, construcción y el control de calidad del código.

3. Contenedores

Empaquetado aislado utilizando Docker y Nginx para garantizar que el software funcione idénticamente en cualquier entorno.
